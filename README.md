# 🏥 ATHENA AI , CHATBOT FOR PHYSICAL HEALTH SUPPORT
A fast and simple healthcare chatbot that provides predefined health information without unnecessary complexity.

### ✨ Key Features
- 🚫 No login or signup
- 🔌 No external API required
- 🗄️ No database required
- ⚡ Fast, lightweight, and easy to use
- 📋 Predefined health information for consistent responses

**Why templates?** Health information requires care. Predefined responses help keep answers consistent and avoid unpredictable AI-generated advice. However, templates can still be incomplete or outdated and should not replace professional medical guidance.

### 🛠️ Built With
React • Vite • JavaScript • CSS

### 🚀 Run Locally
```bash
npm install
npm run dev
```
